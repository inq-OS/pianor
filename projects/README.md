# Projects

Notes a Claude project keeps for itself that do not belong in a doc of the game. There are no mailboxes (d153): the builder and the painter talk through tags in the feature files and lines in pull requests ([work-model.md](../docs/automation/work-model.md)).

- [painter/](painter/): the painter's artist notes (house recipes for things that turn up in more than one picture) and vocabulary (what each studied picture teaches).
- The painter's notes under `projects/painter/` go through a docs-only pull request, merged once `npm run docs:check` passes ([labels.md](../docs/architect/labels.md)).
