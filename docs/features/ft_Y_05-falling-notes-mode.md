# ft_Y_05: Falling-notes mode

Phase: none. Status: **rejected by AX-0** ([axioms](../axioms.md), AX-0.1: nothing lets the student play without reading). Kept as a record; do not build it. Index: [FEATURES.md](FEATURES.md).

An optional falling-notes practice mode for fun or rhythm practice, never as a replacement for the staff. Falling notes let a student play without reading, so the staff stays the main view and this comes last if at all (`docs/decisions/notation.md#d002`).

The rendering split keeps it cheap: a falling-notes view is another view over the same chart and the same play state (`docs/futureproofing.md` 1.4).
