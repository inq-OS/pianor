# Music theory reference

The music theory Pianor builds on, for agents and the maintainer when a feature has to get the theory right. It is reference, not features, and it is never shown to the student. One page per topic; add a page when a feature needs a topic that is not here, and link it below.

How notation is drawn (clefs, accidentals, key signature places, the grand staff) is in [notation.md](../notation.md); this folder is about the music itself.
